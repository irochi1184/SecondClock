# SecondClock App Store提出パッケージ

このフォルダには、App Store Connect（ASC）への初回提出に必要な制作物と入力原稿をまとめています。

## 採用案

- アプリ名：`SecondClock – 秒まで見える時計`
- 主カテゴリ：ユーティリティ
- 収益化：無料ダウンロード＋買い切りの非消耗型アプリ内課金
- Pro初期価格案：700円
- 採用アイコン：`Brand/AppIcon-approved-v3-1024.png`（エメラルド＋オレンジ）
- 日本語スクリーンショット：`Screenshots/Final-ja/`（全4枚・横向き）

## フォルダ

- `Brand/`：旧却下案、比較候補、採用アイコン、客観評価
- `Screenshots/`：ASC掲載用画像、比較案、再生成スクリプト
- `Metadata/`：商品ページへコピーする文面
- `Review/`：審査メモ、IAP審査画像、質問票の回答案
- `Site/`：サポート・プライバシー・製品紹介サイト
- `ASC-Submission-Checklist.md`：提出作業の順序と未入力項目

App Store Connectのアカウント、契約、銀行・税務、本人情報、価格設定、公開操作は開発者本人の確認が必要です。
