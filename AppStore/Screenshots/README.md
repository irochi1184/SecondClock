# スクリーンショット設計

## 採用：Landscape Editorial

採用アイコンに合わせた濃紺・エメラルド・オレンジの配色で、大きな便益訴求と実際のアプリ画面を組み合わせた横向き専用デザインです。

掲載順：

1. 秒まで美しく見える全画面時計
2. 横向き対応
3. サイズ・書体の変更
4. 単色・グラデーション・写真背景

`Final-ja/`と`Final-en/`の各4枚は、すべて横向きの2868×1320、RGB、不透明PNGです。

## 注意

- 時計画面はiPhone 16 Pro Maxシミュレータから横向きで取得した実アプリ表示です。
- 設定訴求の3枚目も提出画像自体は横向きで、設定画面と横向きプレビューを並べています。
- IAP審査用の`Review/iap-review.png`も横向きの2868×1320です。
- Pro限定機能を含む4枚目には注記を入れています。
- 価格は地域により変わるため、公開用スクリーンショットには記載していません。
- `Final-en/`は将来の英語UI対応後に使う草案です。現状のアプリUIは日本語のため初回提出には使用しません。

再生成：リポジトリ直下で`swift AppStore/Screenshots/make_screenshots.swift`を実行します。
